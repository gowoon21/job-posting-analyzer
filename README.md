# Job Posting Analyzer
 채용공고를 자동으로 수집하고 분석하여
 자주 등장하는 기술 스택과 채용 트렌드를 시각화하는 프로젝트입니다.

 ## Project Goals
 - 채용공고 자동 수집
 - 기술 스택 추출
 - 데이터 분석
 - 통계 시각화

 ## Tech Stack
 - Python
 - BeautifulSoup
 - Requests
 - Pandas
